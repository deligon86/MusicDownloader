# Music Downloader with Kivy/KivyMD using MVVM
## ⚠️DISCLAIMER⚠️
This app is as an experiment for creating applications using MVVM architecture with kivy/kivymd. 
Much of the code needs optimizations and rewrite to follow the design principles, this is just a prototype and see what can be achieved with kivy.

## NOTE: Some functionalities are only supported in Windows Os

## Supported source sites
Currently supported data sources are:
* Americatop40
* Billboard Chart
* Hiphopkit
* Justnaija
* YouTube
